The Strategy Retreat 2026  ●  Icon set

Nineteen icons, drawn for this page and nowhere else.

No icon library is used anywhere in the build. Every mark is hand-drawn on the same 24×24 grid at the same stroke weight, which is what makes them read as one set at 17px in a values row and at 34px on a methodology node.

19 icons grid 24 × 24 stroke 1.7, round caps colour currentColor 2 solid, 17 outline files in assets/icons/
Each tile shows the icon twice: on the page’s light ground, and on the navy the methodology and CTA sections use. Colour is never baked into the file — every icon inherits currentColor from its container, so one file serves both.
